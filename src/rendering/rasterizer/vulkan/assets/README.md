# Scalar spatiotemporal blue noise

`stbn_128x128x64.bin` is a 128 x 128 x 64 scalar STBN volume, in Z/Y/X order,
with one unsigned byte per voxel. It is generated by this repository's
[`scripts/generate_stbn.cpp`](../../../../../scripts/generate_stbn.cpp).
No third-party source code or texture data is included.

The generator implements the generalized void-and-cluster algorithm from
[Wolfe et al., supplemental section 4.2](https://cseweb.ucsd.edu/~ravir/stbn_supplemental.pdf).
Its toroidal energy is the sum of a Gaussian within each XY slice and a
Gaussian along each Z column. Sigma is 1.9 on both groups, with radius 8 and
integer energy weights. This is not an ordinary three-dimensional blue-noise
volume or a stack of independent spatial masks.

```sh
c++ -O3 -std=c++20 scripts/generate_stbn.cpp -o generate_stbn
./generate_stbn src/rendering/rasterizer/vulkan/assets/stbn_128x128x64.bin
```

The fixed seed is `0x5354424e`. Ranks are quantized to 256 equally populated
bins. Shader sampling adds a full-precision primitive phase, R2 spatial offsets,
and a golden-ratio rotation between complete 64-frame periods. The volume is
embedded at build time, uploaded once on first use, and shared by all views.
