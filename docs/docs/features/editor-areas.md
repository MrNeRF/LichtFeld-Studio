# Editor areas

Editor areas let you arrange tools around the 3D view and save that workspace
with your project.

## Split, resize, join, and swap

Drag from an area's corner to create another area. Move the pointer toward an
edge to join with a neighboring area, or toward the middle to split. The area
header menu also has vertical and horizontal split commands. Drag a divider to
resize the areas on either side.

Hold **Ctrl** while dragging from a corner into another area to swap the two
editors. Each area keeps its own editor state when it moves. Use the area's
header menu to close an area when the layout allows it.

## Maximize and four views

Point at an area and press **Ctrl+Space** to maximize it. Press the shortcut
again to restore the layout. The pointer determines which area is maximized,
including areas showing panels.

Press **Ctrl+Alt+Q** in a 3D view to switch between one view and four views.
The four-view layout shows top, front, and right orthographic views alongside
the original view.

## Choose an editor

Use the editor icon at the left of an area header to choose the editor shown
there. Available editors depend on the panels and tools registered in the
current session. Switching away and back keeps that area's editor state.

## 3D view controls

The 3D view header contains display modes for splats, points, rings, and center
markers, plus depth display, overlays, and projection controls. In narrow
areas, some controls move into a compact display menu. The **View** menu also
contains framing commands, projection, area layout commands, and named
viewpoints.

Use the numpad shortcuts for top (**Numpad 7**), front (**Numpad 1**), right
(**Numpad 3**), and perspective or orthographic projection (**Numpad 5**).
Hold **Ctrl** with Numpad 7, 1, or 3 to look from the opposite side.

The screen layout and each area's editor settings are saved with the project.
