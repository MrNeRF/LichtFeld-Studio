COVERED LIBRARIES

"NVIDIA GPU Libraries" means the following NVIDIA software, in object code
form, when it is obtained under NVIDIA's own license terms:

  a. the redistributable runtime libraries of the NVIDIA CUDA Toolkit, as listed
     in the CUDA Toolkit End User License Agreement (for example the CUDA
     Runtime, the CUDA device runtime, cuRAND, nvJPEG and NVTX);
  b. the NVIDIA nvJPEG2000 library;
  c. the NVIDIA GPU driver and the libraries installed with it, including the
     CUDA Driver API and the NVIDIA Video Codec SDK runtime (NVENC, NVDEC);
  d. the NVIDIA DLSS SDK and NVIDIA NGX SDK runtime libraries, when an optional
     LichtFeld Studio component uses them.
